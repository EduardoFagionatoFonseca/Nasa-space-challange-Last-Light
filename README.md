# LAST LIGHT

Jogo de estratégia e sobrevivência lunar em desenvolvimento para Godot 4.7. Uma campanha dura sete dias; a tripulação precisa sobreviver e completar três etapas de resgate.

## Estado atual

O núcleo da simulação está implementado e testado. A cena 3D e a interface estão em construção. Este marco ainda não é uma versão jogável.

## Teste da simulação

Abra um terminal na pasta do projeto e execute:

```text
godot --headless --path . --script res://tests/model_test.gd --quit
```

No ambiente de desenvolvimento, o Godot 4.7 foi encontrado em `C:\Users\eduar\Downloads\Godot_v4.7-stable_win64.exe\Godot_v4.7-stable_win64_console.exe`.
