# Assets e licença

O diorama lunar, painéis solares, módulos principais, rochas procedurais, estrelas, iluminação, interface e áudio são produzidos por código no próprio projeto. Os sons são sintetizados em tempo de execução por `scripts/soundscape.gd`; não há arquivo de áudio de terceiro.

Os modelos `.obj` e materiais `.mtl` em `assets/kenney_space_kit/` vieram do [Kenney Space Kit](https://kenney.nl/assets/space-kit). A [licença incluída](../assets/kenney_space_kit/License.txt) declara CC0. Foram selecionados astronauta, rover, gerador, antena, estrutura de estufa e rochas. Os arquivos `.obj.import` guardam as opções de importação do Godot. O projeto funciona offline após importado.

Crédito voluntário: **Kenney — Space Kit (CC0)**. Nenhum modelo da NASA é usado no jogo.
